# Aldr Health Provider Full Demo

This is the full-featured demonstration of the Aldr Health platform for healthcare providers (previously known as SOMA Colleague).

## Overview

Aldr Health Provider offers a comprehensive interface for healthcare providers to access and manage patient health data shared through the Aldr platform. It enables efficient patient care management while maintaining patient data privacy and security.

## Project Structure

```
aldr-health-provider-full-demo/
├── docs/               # Documentation files
├── public/             # Public assets and HTML
└── src/                # Source code
    ├── assets/         # Images, fonts, and other static assets
    ├── components/     # Reusable components
    ├── contexts/       # React contexts for state management
    ├── hooks/          # Custom React hooks
    ├── layouts/        # Layout components
    ├── pages/          # Page components
    ├── services/       # API service integrations
    └── utils/          # Utility functions
```

## Features

- Patient record access and management
- Care plan creation and monitoring
- Provider dashboard with analytics
- Secure patient communication
- Multi-specialty support

## Getting Started

1. Install dependencies: `npm install`
2. Start the development server: `npm start`
3. Build for production: `npm run build`

## Technology Stack

- React
- React Router
- TailwindCSS
- Axios
