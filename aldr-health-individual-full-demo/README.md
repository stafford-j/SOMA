# Aldr Health Individual Full Demo

This is the full-featured demonstration of the Aldr Health platform for individual users (previously known as SOMA Companion).

## Overview

Aldr Health Individual provides a comprehensive health data management interface for individual users. It allows users to store, access, and share their health records securely while maintaining control over their data.

## Project Structure

```
aldr-health-individual-full-demo/
├── docs/               # Documentation files
├── public/             # Public assets and HTML
└── src/                # Source code
    ├── assets/         # Images, fonts, and other static assets
    ├── components/     # Reusable components
    ├── contexts/       # React contexts for state management
    ├── hooks/          # Custom React hooks
    ├── layouts/        # Layout components
    ├── pages/          # Page components
    ├── services/       # API service integrations
    └── utils/          # Utility functions
```

## Features

- Health record management
- Care plan visualization and tracking
- Secure sharing with healthcare providers
- Comprehensive dashboard views
- Profile and settings management

## Getting Started

1. Install dependencies: `npm install`
2. Start the development server: `npm start`
3. Build for production: `npm run build`

## Technology Stack

- React
- React Router
- TailwindCSS
- Axios
