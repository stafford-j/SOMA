# Aldr Vaults Brand Guidelines

## Brand Overview
Aldr Vaults is a secure document storage platform that provides users with a structured way to store and manage important documents across Health, Legal, and Identity categories.

## Logo Usage

### Primary Logo
![Aldr Logo](/assets/aldr-logo-hq.png)
- **Usage**: Navigation bars, app icons, and primary branding
- **Minimum Size**: Maintain a height of at least 24px to ensure legibility

### Logo with Tagline
![Aldr Logo with Tagline](/assets/aldr-logo-tagline.png)
- **Usage**: Footer, marketing materials, and documentation
- **Minimum Size**: Maintain a height of at least 60px to ensure tagline legibility

## Color Palette

### Primary Colors
| Color | Hex Code | Usage |
|-------|----------|-------|
| Teal | #20B2AA | Primary accent color, buttons, active elements |
| Purple | #8A2BE2 | Secondary accent, hover states, highlights |

### Secondary Colors
| Color | Hex Code | Usage |
|-------|----------|-------|
| Dark | #333333 | Main text, headings |
| Light | #F8F9FA | Backgrounds, light elements |
| Gray | #6C757D | Secondary text, muted UI elements |

### Gradient
The Aldr brand gradient flows from Teal (#20B2AA) to Purple (#8A2BE2) at a 45-degree angle.
- **Usage**: Headers, cards, and prominent UI elements

## Typography

### Primary Font
- **Font Family**: Segoe UI, Tahoma, Geneva, Verdana, sans-serif
- **Weights Used**: Regular (400), Medium (500), Bold (700)

### Text Styles
| Style | Font | Weight | Size | Color | Usage |
|-------|------|--------|------|-------|-------|
| H1 | Segoe UI | Bold | 2.25rem (36px) | Gradient or Dark | Page headers |
| H2 | Segoe UI | Bold | 1.5rem (24px) | Dark | Section headers |
| Body | Segoe UI | Regular | 1rem (16px) | Dark | Main content |
| Small | Segoe UI | Regular | 0.875rem (14px) | Gray | Secondary content |

## UI Components

### Buttons
#### Primary Button
- Background: Gradient from Teal to Purple
- Text: White
- Border-radius: 50px (pill)
- Padding: 0.75rem 1.75rem (py-3 px-7)

#### Secondary Button
- Background: Transparent
- Border: 1px solid Teal
- Text: Teal
- Border-radius: 50px (pill)
- Padding: 0.75rem 1.75rem (py-3 px-7)

### Cards
- Background: White
- Border-radius: 0.5rem (8px)
- Shadow: md (tailwind shadow-md)
- Padding: 1.5rem (24px)

### Icons
- Font Awesome 6 (solid style)
- Primary color: Teal or White (on dark backgrounds)
- Size: 1rem for inline, 1.5rem for standalone

## Layout Guidelines

### Spacing
- Base unit: 0.25rem (4px)
- Content padding: 1rem (16px) on mobile, 2rem (32px) on desktop
- Element spacing: 1.5rem (24px) between major sections

### Breakpoints
- **Mobile**: < 640px
- **Tablet**: 640px - 1024px
- **Desktop**: > 1024px

## Animation

### Transitions
- Duration: 300ms
- Easing: ease-in-out
- Elements: buttons, cards, and interactive elements

## Voice and Tone
- **Clear**: Simple and direct language
- **Reassuring**: Emphasize security and trust
- **Helpful**: Focus on utility and problem-solving
- **Professional**: Maintain a business-appropriate tone

## Use Cases
- Health documents (medical records, insurance)
- Legal documents (contracts, agreements)
- Identity documents (ID cards, certificates)
