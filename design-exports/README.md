# Aldr Vaults Design Package

This package contains design specifications, guidelines, and assets for the Aldr Vaults application. It is intended for developers implementing the design.

## Package Contents

### Guidelines
- `guidelines/aldr-brand-guidelines.md` - Complete brand guidelines including colors, typography, and voice
- `guidelines/component-specifications.md` - Detailed specifications for all UI components
- `guidelines/css-reference.md` - CSS and Tailwind classes reference for implementation

### Assets
- `assets/aldr-logo-hq.png` - High-quality Aldr logo for navigation
- `assets/aldr-logo-tagline.png` - Aldr logo with tagline for footer

## Implementation Notes

### Tech Stack
- React for the frontend framework
- TailwindCSS for styling
- Font Awesome for icons

### Key Design Principles
1. **Clarity** - Clean layouts with clear visual hierarchy
2. **Consistency** - Consistent use of colors, spacing, and components
3. **Responsiveness** - Designs adapt seamlessly across device sizes
4. **Visual Identity** - Strong brand presence with the teal-purple gradient

## Getting Started

1. Review the brand guidelines for color and typography specifications
2. Examine component specifications for detailed implementation requirements
3. Use the CSS reference for exact styling instructions
4. Implement designs starting with the layout structure, then components
